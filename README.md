# Bike Landing Page

- [DEMO LINK](https://itisandrew25-ship-it.github.io/landing/)

## 📌 Project Description
A modern, fully responsive landing page developed for a bicycle brand, designed to showcase products and key features with an intuitive, polished user interface.

## Key Advantages & Features:
- **Responsive Layout:** Mobile-first approach ensuring a seamless and adaptive user experience across mobile devices, tablets, and desktops.
- **Scalable Architecture:** Built using semantic HTML5 and a modular SCSS structure following the **BEM methodology** for clean, maintainable, and reusable styles.
- **Interactive Enhancements:** Smooth user interactions and dynamic elements powered by vanilla JavaScript (ES6+).
- **Optimized Performance:** Automated build workflow and asset optimization handled via **Gulp**, ensuring fast loading speeds and high performance.
- **Code Quality:** Strict adherence to code standards maintained using Stylelint and ESLint.

## 🛠 Technologies Used
- **HTML5** / Semantic markup
- **SCSS (SASS)** / BEM methodology
- **JavaScript (ES6+)**
- **Gulp** (Task Runner)
- **Stylelint** & **ESLint** for code quality

## 🚀 Getting Started
To get a local copy up and running, follow these simple steps:

1. Clone the repository:
   ```bash
   git clone [https://github.com/itisandrew25-ship-it/landing.git](https://github.com/itisandrew25-ship-it/landing.git)
   cd landing
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the project locally:
   ```bash
   npm start
   ```
